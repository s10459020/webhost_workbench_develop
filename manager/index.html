SHV Homepage

選擇要進入的功能頁面

當前使用版本:

版本設定由 manager/config/server.json 提供。

V3

Web Explorer

單一版本入口（統一使用 type2/scan2/read2）。

 Tests

API Tests

逐行執行並顯示 file API 測試狀態，可直接編輯測試腳本。

 Info

PHP Info

檢視當前 PHP/Server/限制參數，方便對照 phpinfo 與環境設定。

 Preview

Preview

進入 Preview 頁面後可動態修改 path。

 Browser

Browser

輸入網址後在下方內嵌瀏覽頁面內容。

 MySQL

MySQL

輸入連線資訊後預覽資料庫、資料表與 SQL 查詢結果。

 FTP

FTP

連線 FTP 後可瀏覽、上傳、下載、刪除遠端檔案。

 CMD

Command

透過封裝 API 執行主機命令，顯示輸出與結束代碼。
